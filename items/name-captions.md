# Name captions

An optional name under each portrait, showing "???" until the GM reveals it. Useful when players meet many NPCs and some shouldn't be named yet.

**Decisions (Justin, 2026-10-30):**
- **A world setting** turns captions on for the whole world. Off by default.
- **The name** is the actor's name, or the art name for a character without an actor.
- **Starting state:** party members start named; everyone else starts as "???".
- **Reveal:** "Reveal name" and "Hide name" in the GM's character menu.
- **It sticks:** the revealed state is saved on the actor (an actor flag, like expressions and forms), so a named NPC stays named on every stage. A character without an actor keeps it on its cast entry.

**Open for build:** where exactly the caption sits. Default: centred under the portrait near the bottom edge of the frame, above the bottom shade. Check it in Foundry with Justin.
