# Items

Every feature, idea and decision for VN Stage that isn't finished, one note each. The frontmatter holds `status`, `waits_on`, `priority` and the dates; the body holds the context and the next step. Finished items move to `done/` with an `outcome` line; dropped items stay, with the reason.

**Add an idea** by copying any note here: `kind: idea`, `status: proposed`, `waits_on: Justin`, and no `priority` until it's triaged.
