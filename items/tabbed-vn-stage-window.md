# Test a tabbed VN Stage window

Try a new version of the VN Stage window with three tabs: **Presets**, **Background** and **Cast**.

**Why:** the window holds several sections at once. Tabs would let each section have the room it needs.

**Check:** does the window read more easily with tabs? Does moving between presets, backgrounds and cast feel quicker than scrolling? Does anything get hidden that needs to stay in view during a scene?

**Next step:** Justin decides whether to build the tabbed version as a test. It should sit beside the current window until he picks one.
